## About This Repository

This repository records my learning and engineering practice in the **YSYX (“One Student One Chip”)** initiative.

The goal is not merely to implement a textbook five-stage pipeline, but to understand and build a computer system across the entire software–hardware stack:

- Develop Linux and C programming skills.
- Build a RISC-V emulator capable of running real programs and games.
- Understand instruction execution, system calls, memory, caches, and system boot.
- Implement operating-system components and study how software runs on hardware.
- Design and verify an RTL processor capable of running RT-Thread.
- Integrate the processor into an SoC.
- Explore synthesis, physical design, timing analysis, open-source EDA tools, and chip tape-out.
- Develop independent debugging and problem-solving abilities.

This repository preserves my code, experiments, debugging records, notes, and reflections—from the first C program to a complete processor system.

Official YSYX website: [https://ysyx.oscc.cc/en/](https://ysyx.oscc.cc/en/)
